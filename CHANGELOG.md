# Changelog

## [1.4.0](https://github.com/Payfast/prestashop-aggregation/releases/tag/v1.4.0)

### Added

- PrestaShop 9 compatibility.
- PHP 8.3 support.
- Updated Common Library to version 1.4.1.
- Updated branding to use the Payfast by Network logo.
- Revised configuration branding to Payfast Aggregation.
- Better input validation and type casting for configuration settings.
- Twig-based admin configuration page for improved maintainability and user experience.
